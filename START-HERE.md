## 🎯 COMMON TASKS

### **Task 1: View the Website**
```
Action: Double-click index.html
Result: Website opens in browser ✅
```

### **Task 2: Add University Logo**
```
1. Get logo file (PNG recommended)
2. Rename to: university-logo.png
3. Place in: assets/images/
4. Refresh website ✅
```

### **Task 3: Add Gallery Photos**
```
1. Collect cultural event photos
2. Name them: cultural1.jpg, cultural2.jpg, etc.
3. Place in: assets/gallery/
4. Refresh website
5. Gallery appears automatically! ✅
```

### **Task 4: Change Event Date**
```
1. Open: config.js (in Notepad or any text editor)
2. Find: eventDate: "2026-10-15T09:00:00"
3. Change the date if needed
4. Save file
5. Refresh website ✅
```

### **Task 5: Put Website Online**
```
1. Go to: github.com
2. Sign in (or create free account)
3. Create new repository: cultural-day-2026
4. Upload all files
5. Enable GitHub Pages in Settings
6. Get your URL: https://username.github.io/cultural-day-2026/
7. Share everywhere! ✅
```
