# ⚡ Quick Start Guide

## Get Your Website Running in 5 Minutes!

This is the fastest way to get your Cultural Day 2026 website up and running.

---

## 🚀 STEP 1: Open the Website

1. **Find the file:** `index.html`
2. **Double-click it**
3. **Website opens in your browser!** ✅

**That's it!** The website works immediately, no installation needed.

---

## 📸 STEP 2: Add Your Content (Optional)

### **Add University Logo**

1. Get your university logo (PNG format recommended)
2. Rename it to: `university-logo.png`
3. Place it in: `assets/images/`
4. Refresh the website

### **Add Campus Photos**

1. Get 2-6 campus/cultural photos
2. Name them: `campus1.jpg`, `campus2.jpg`, etc.
3. Place them in: `assets/images/`
4. Refresh the website

### **Add Gallery Photos**

1. Collect cultural event photos
2. Name them: `cultural1.jpg`, `cultural2.jpg`, etc.
3. Place them in: `assets/gallery/`
4. Refresh the website
5. Gallery automatically appears!

### **Add Videos (Optional)**

1. Get cultural event videos (MP4 format)
2. Name them: `video1.mp4`, `video2.mp4`, etc.
3. Place them in: `assets/videos/`
4. Refresh the website

---

## ⚙️ STEP 3: Update Event Details

1. **Open:** `config.js` in any text editor (Notepad works!)
2. **Find this section:**

```javascript
const CULTURAL_CONFIG = {
    universityName: "Guru Nanak University",
    location: "Hyderabad",
    eventName: "Cultural Day 2026",
    eventDate: "2026-10-15T09:00:00",
    eventDateDisplay: "15 OCTOBER 2026",
};
```

3. **Change the details** if needed
4. **Save the file**
5. **Refresh the website**

---

## 🌐 STEP 4: Put It Online (GitHub Pages)

### **Super Quick Method:**

1. **Go to:** [github.com](https://github.com)
2. **Sign in** (or create free account)
3. **Click:** "New repository"
4. **Name it:** `cultural-day-2026`
5. **Set:** Public
6. **Click:** "Create repository"
7. **Click:** "uploading an existing file"
8. **Drag all files** into the upload area:
   - index.html
   - style.css
   - script.js
   - config.js
   - README.md
   - assets folder (entire folder)
9. **Click:** "Commit changes"
10. **Go to:** Settings → Pages
11. **Select:** main branch, / (root)
12. **Click:** Save
13. **Wait 2 minutes**
14. **Your website is live!**

**Your URL will be:**
```
https://YOUR-USERNAME.github.io/cultural-day-2026/
```

## ❓ Need Help?

### **Website Not Working?**
1. Make sure all files are in the same folder
2. Check that `assets` folder exists
3. Use Chrome or Firefox browser
4. Press F12 to see any errors

### **Images Not Showing?**
1. Check files are in correct folders:
   - Logo → `assets/images/`
   - Gallery → `assets/gallery/`
2. Check filenames match exactly
3. Make sure images are JPG or PNG

### **Countdown Not Working?**
1. Check date format in `config.js`
2. Should be: `"2026-10-15T09:00:00"`
3. Year-Month-Day format
4. Include the T and time

### **GitHub Pages Not Working?**
1. Wait 5 minutes after enabling
2. Make sure repository is Public
3. Check `index.html` is in root (not in subfolder)
4. Try opening in private/incognito browser
