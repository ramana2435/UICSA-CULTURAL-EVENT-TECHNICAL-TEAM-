# Gallery Folder

## 📸 Add Cultural Event Photos Here

### Instructions:
1. Place all cultural event photographs in this folder
2. The website will automatically detect and display them
3. Photos will appear in a beautiful masonry-style gallery
4. Users can click photos to view them in full-screen lightbox

### Naming Convention:
Use simple, sequential names for easy management:
- cultural1.jpg
- cultural2.jpg
- cultural3.jpg
- event1.jpg
- event2.jpg
- photo1.jpg
- photo2.jpg

### Supported Formats:
- JPG / JPEG (recommended)
- PNG
- WEBP
- GIF

### Recommendations:
- **Resolution:** 1920x1080 or higher
- **Aspect Ratio:** Any (landscape, portrait, square all work)
- **File Size:** Under 2MB per image (compress if needed)
- **Quantity:** Add as many as you want! The gallery is unlimited

### Image Optimization:
If your images are too large:
1. Use online tools like TinyPNG.com or Squoosh.app
2. Compress before uploading
3. This ensures faster website loading

### What to Photograph:
- 🎭 Cultural performances
- 💃 Dance performances
- 🎤 Singing performances
- 🎨 Art displays
- 👥 Student groups
- 🎉 Celebration moments
- 🏛️ Event venue
- 🎊 Decorations
- 📸 Candid moments

## 📝 After Adding Photos:
1. Refresh the website
2. Gallery will automatically populate
3. No code changes needed!
