# Videos Folder

## 🎥 Add Cultural Event Videos Here

### Instructions:
1. Place all cultural event videos in this folder
2. The website will automatically detect and display them
3. Videos will appear in a responsive grid
4. Users can play videos directly on the website

### Naming Convention:
Use simple, sequential names:
- video1.mp4
- video2.mp4
- cultural1.mp4
- cultural2.mp4
- performance1.mp4

### Supported Formats:
- **MP4** (recommended - best compatibility)
- WEBM
- OGG

### Recommendations:
- **Resolution:** 1920x1080 (Full HD) or 1280x720 (HD)
- **Duration:** Keep videos under 5 minutes for best performance
- **File Size:** Under 50MB per video (compress if needed)
- **Codec:** H.264 for MP4 (most compatible)

### Video Optimization:
If your videos are too large:
1. Use HandBrake (free software) to compress
2. Or use online tools like Clipchamp
3. Recommended settings:
   - Format: MP4
   - Codec: H.264
   - Bitrate: 2-5 Mbps
   - Audio: AAC, 128 kbps

### What to Record:
- 🎭 Cultural performances
- 💃 Dance performances
- 🎤 Singing performances
- 🎬 Event highlights
- 🎙️ Speeches and announcements
- 🎊 Opening/Closing ceremonies
- 📹 Behind-the-scenes moments
- 🎉 Celebration montages

### Mobile Compatibility:
- Videos will work on mobile devices
- Use MP4 format for best mobile support
- Keep file sizes reasonable for mobile data

## 📝 Notes:
- Videos will NOT autoplay (user-friendly)
- Users click to play videos
- Videos include standard controls (play, pause, volume, fullscreen)
- Supports touch controls on mobile

## 🚀 After Adding Videos:
1. Refresh the website
2. Videos will automatically appear
3. No code changes needed!
