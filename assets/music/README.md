# Music Folder

## 🎵 Add Audio Files Here

### Optional Audio Files:

#### 1. **cultural-music.mp3**
- Background music for the website
- Will loop continuously when user plays it
- User can toggle on/off with music button
- Creates atmospheric cultural ambiance

**Recommendations:**
- Duration: 2-5 minutes (will loop)
- Volume: Moderate (not too loud)
- Style: Instrumental cultural/classical music
- Format: MP3 (best compatibility)
- Bitrate: 128-192 kbps
- File Size: Under 10MB

**Suggested Music:**
- Indian classical instrumental
- Cultural fusion music
- University anthem (instrumental)
- Calm background ambiance

## 📝 Important Notes:

### Browser Autoplay Policies:
- Modern browsers block audio autoplay
- Users MUST click a button to play audio
- This is a security feature - we cannot bypass it
- The website handles this gracefully

### If Audio Files Are Missing:
- Website will continue to work normally
- Audio buttons will be automatically hidden
- No broken features
- No errors

### Adding Audio Files:
1. Place files in this folder with exact names:
   - `cultural-music.mp3`
   - `welcome.mp3`
2. Refresh website
3. Audio buttons will appear automatically
4. Test on multiple browsers

### File Format:
- **MP3** is highly recommended
- Best browser compatibility
- Works on mobile devices
- Universal support

### Creating Audio:
- Record with any voice recording app
- Edit with Audacity (free software)
- Export as MP3, 128 kbps
- Normalize audio levels
- Remove background noise

### Copyright:
- Only use royalty-free music
- Or music you have permission to use
- Original recordings are best
- Free music sources:
  - YouTube Audio Library
  - Free Music Archive
  - Incompetech.com
