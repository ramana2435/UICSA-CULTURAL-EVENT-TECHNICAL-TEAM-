## 🐛 COMMON ISSUES

### **If Something Doesn't Work:**

1. **Hard refresh:** Ctrl+Shift+R (Cmd+Shift+R)
2. **Clear cache:** Browser settings
3. **Check console:** F12 for errors
4. **Verify files:** All uploaded correctly
5. **Check paths:** Relative, not absolute
6. **Test different browser:** Isolate issue
7. **Check mobile:** Responsive layout
8. **Review code:** Recent changes
